# Portfolio

A showcase of my first-year engineering design projects. Each page is a single self-contained HTML file, with the project photos built in.

## Projects

### [Slide N’ Store Container System](https://maazh904.github.io/portfolio/slide-n-store.html)
A modular storage system for a wheelchair user with juvenile rheumatoid arthritis. Parts slide onto a rigid baseplate, magnets replace hard-to-open Velcro, and a ball launcher attachment lets him play with his dog. Runner Up out of 200+ projects.

**My part:** materials and sources research, magnet seal idea and slot design, test plan and data tables, user survey, launcher circuit and wiring.

### [Q-Arm End Effector](https://maazh904.github.io/portfolio/q-arm-end-effector.html)
A custom gripper and ordering software that lets a Q arm pick up objects of different shapes and sizes and place them into parcels for warehouse package handling.

**My part:** team coordinator (meetings, minutes, action items), two gripper designs in CAD, the user authentication code, and software flowcharts.
